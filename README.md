# Indian Agriculture Crop Production Analysis (1997–2021)

## Overview

This project analyzes India's agricultural cultivation and crop production from 1997–98 to 2020–21 using Tableau. The analysis explores crop production, cultivated area, yield, seasonal variations, state-wise distribution, and yearly production trends.

## Problem Statement

To analyze historical agricultural data and identify patterns in crop production, cultivated area, yield, seasonal variations, and regional differences to support data-driven agricultural decisions.

## Dataset

- Source: Skill Wallet
- Format: Excel
- Records: 345,409
- Columns: 10
- Period: 1997–98 to 2020–21

## Main Fields

State, District, Crop, Year, Season, Area, Production, Production Units, Yield.

## Data Preparation

The dataset was inspected for data types, missing values, numerical fields, geographic fields, and measurement units before being connected to Tableau for analysis.

## Key Insights

- Agricultural production varies significantly across Indian states.
- Different crops occupy different amounts of cultivated area.
- Production changes across years and seasons.
- The analysis highlights differences in agricultural activity across regions and crop categories.

## Conclusion

The project demonstrates how Tableau can transform historical agricultural data into interactive visualizations and meaningful insights for farmers, policymakers, and agribusiness stakeholders.
